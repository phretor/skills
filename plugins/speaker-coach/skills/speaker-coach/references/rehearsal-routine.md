# Rehearsal Routine

Used by `rehearse` mode (readiness gate). Walk the speaker through the timeline; mark each item as **done / in-progress / not started / N/A**. Refuse to claim "ready" until at least the T-2-weeks slate is at "done."

## T-1 month and earlier — messaging

- [ ] Target audience subset named (not "everyone").
- [ ] Core message (280-char takeaway) written down.
- [ ] 3+ sub-messages (topic sentences) written down.
- [ ] Legal / disclosure aspects settled (NDA scope, vendor coordination, embargo).

## T-1 month — core material drafted

- [ ] Core message final and the speaker is convinced of it.
- [ ] Supporting messages crisp.
- [ ] Outline 90% final.
- [ ] Sources for illustrations identified (50–70%).
- [ ] Demos 80% done.
- [ ] **No slides built yet** (intentional).

## T-3 weeks — story done

- [ ] Outline finalized.
- [ ] Outline moved to speaker notes.
- [ ] Simple illustrations drafted on paper or as rough sketches in slides.
- [ ] Complex illustrations have placeholder text describing what they'll show.

## T-2 to 3 weeks — content finalized

- [ ] Slides 90% final.
- [ ] 1 recorded rehearsal every 1–2 days.
- [ ] Slides + speaker notes edited *immediately* after each rehearsal (no "I'll do it later").

## T-1 to 2 weeks — environment + tech

- [ ] Room layout known (got it from organizers or visited).
- [ ] Podium vs stage decision made.
- [ ] Microphone type confirmed (lavalier, handheld, headset).
- [ ] Prompter requested if needed (and tech aware).
- [ ] Stage walked through the day before, if possible.
- [ ] 3–5 recorded rehearsals scheduled and on the calendar.

## Day before

- [ ] Rehearse in a similar room. With co-speaker if applicable.
- [ ] Tech check, ideally with the on-site technician.
- [ ] Alarm set to call it a night — no rehearsing before bed.
- [ ] Early morning alarm to rehearse first thing.

## Day-of

- [ ] One rehearsal first thing in the morning, before breakfast.
- [ ] **No slide changes after this rehearsal** (unless legal compels it).

## 2 hours before

- [ ] Locate the speaking room from anywhere in the venue.

## 1 hour before

- [ ] Restroom. Stretching. Facial muscle stretching.

## 30 minutes before

- [ ] Repeat the opening hook out loud, multiple times, if memorization is needed.

## 10 minutes before

- [ ] Clicker tested.
- [ ] Miked up.
- [ ] Sip of water.
- [ ] Candy / sugar on hand.
- [ ] All apps closed except the slide app.
- [ ] All devices in Do Not Disturb.

## 5 minutes before

- [ ] Repeat the first sentence of the opening, out loud, once.

## Seconds before walking on

- Don't look at the laptop. Look at the audience. Embrace it. Make eye contact. Smile. Let your eyes adjust to the stage lights.
