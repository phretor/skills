# News

RSS feed management and intelligence synthesis via the Miniflux MCP server.

## Skills

| Skill | Description |
|-------|-------------|
| `news-reader` | Read, search, triage, and manage RSS feeds through Miniflux |
| `news-chronicle` | Synthesize feeds into domain-clustered security intelligence chronicles |

## Requirements

Both skills require the `miniflux` MCP server to be configured and reachable. If the healthcheck fails, the skills will stop and ask you to configure it.
